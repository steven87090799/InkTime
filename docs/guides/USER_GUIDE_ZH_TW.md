# 使用者指南

新安裝預設本機選片，不會自動產生模型描述。一般 AI 工作需管理員在「設定」開啟 `automatic_ai` 並設定 Provider；完成後從[Activity／AI Trace](ACTIVITY_AI_TRACE_ZH_TW.md)與成本核對模型執行。


## 儀表板與照片

儀表板顯示照片、分析失敗、重複、工作、Token、成本與最近錯誤。照片庫每頁最多 200 張，可搜尋路徑／描述，並依狀態、類型、回憶分與重複群組篩選；篩選條件會保留到上一頁、下一頁與直接跳頁。每張卡片依分析來源顯示描述、電子紙短句與分數；`semantic` 與 `local_quality` 分開計算排序母體，先選 AI 語意候選，本機候選只在允許回退時補足。Schema v4 使用回憶、視覺與本機品質的固定公式及特殊程度加分，E6 僅參與顯示分數；舊版結果標為 `legacy`，需重新分析才進 v4 排名。詳細頁會逐項列出本機預篩選實際數值、目前門檻、是否命中與最終決定，並顯示每次模型分析的分類、回憶／視覺分數、本機品質、特殊程度、內容分類、方向與文字結果、電子紙短句、原始 JSON、Token、成本與錯誤。

儀表板的「已完成分析（含本機）」沿用照片工作狀態；「有模型分析」依照片去重，另外列出現行 v4 與僅有歷史模型結果的張數。照片庫與詳細頁會保留顯示及搜尋舊版模型描述、短句與原始評分，標為「歷史模型判斷」。本機重掃不會遮住這些紀錄；歷史分數不加入 v4 排名或最低 v4 回憶分篩選。

## 分析工作

administrator 可建立本地或單次完整 Vision 工作。啟動前確認預估照片數與預算。`pausing` 表示正在完成已送出的少量工作；進入 `paused` 後不再 claim。取消後不再送新請求；失敗項目可重跑。viewer 只能查看與匯出。舊版低成本／兩階段策略名稱僅作讀取相容，會正規化為單次分析。

## 渲染與裝置

「渲染」的智慧裁切工作室會顯示正式 E6 六色量化預覽、裁切焦點，以及對比、主體、膚色、文字／細節四項分數。系統先保護人臉或主體；管理員可調整水平／垂直位置後儲存，也可恢復自動裁切。可預覽並設為預設的版型包括全版照片、明信片、照片＋日期地點、純雙照片、雙照片各自一句話、智慧自適應回憶、月曆、天氣＋室內溫溼度，所有調整都不修改原始照片。

自動選片預設為「歷年今日」：先選過去年度同月同日的照片，不足時才取前後 7 日及綜合排名候選；範圍與回退規則可在「設定」修改。E6 適合度由本機計算，不再因分數低而排除照片；本機技術品質預篩選與 AI 內容排除分別判斷。最愛不繞過 AI 內容排除，人工恢復才可覆寫；一般女性旅遊照、自拍或生活照不能只因單人女性而判為女性寫真。照片含 GPS 時，支援文字的版型可顯示最近城市，不會顯示精確座標。

「渲染」另內建芫荽手寫風格與霞鶩文楷 TC 文青風格，可先看實際字型預覽再切換；管理員也能上傳其他 TTF／OTF／TTC。正式發布仍會逐段檢查短文案、日期、地點與天氣字元，缺字即明確失敗，不會改用不支援繁中的預設字型。發布會建立不可變版本；回滾只切換 latest。新自製裝置透過短效配對碼、管理員核准與一次性 Device Secret 完成綁定；既有 Legacy 裝置才可重新產生相容 Token，舊 Token 立即失效。

## 錯誤與診斷

先記下穩定錯誤碼，再看錯誤中心的聚合次數、工作與照片。診斷頁可查看資源、資料庫、WAL、快取、Worker 與 Queue；診斷包已排除 Secret、私人路徑與 GPS。
