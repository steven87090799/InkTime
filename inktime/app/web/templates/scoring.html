為什麼採用這個方向？

GitHub 上的 NIMA 將美感與本機品質分開，Siamese NIMA 用相對配對強化細微排序；Facet 也採多維品質與照片剔除。InkTime 保留現有輕量部署，不強制下載大型 PyTorch／TensorFlow 模型，先採同樣的「多維＋相對排序」原則。
