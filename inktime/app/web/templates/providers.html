Provider connection

新增 Provider

依序設定連線、模型與用量邊界。儲存只會建立設定，不會立即呼叫模型或產生費用。

1

基本連線

選擇服務類型，填入端點與認證資料。

OpenAI官方雲端 API

適合直接使用 OpenAI Vision 模型；需要有效 API Key。

OpenRouter多模型路由

可指定模型、免費路由或路由規則；不支援 InkTime Batch。

相容 API第三方服務

服務必須相容 OpenAI Chat Completions 與 Vision 輸入格式。

Ollama本機／區網

適合自架模型；只有此類型可直接使用私有 HTTP 端點。

2 模型選擇

決定每次請求由路由器選模型、固定使用一個模型，或沿用 InkTime 系統預設。

免費自動選擇會使用 openrouter/free；實際服務模型會記錄在 AI Trace。

3

進階路由選項

一般情況可留空；只有 Provider 文件明確要求時才設定。

4

流量限制與可靠性

控制路由優先序、並行量、用量上限與失敗後的保護時間。

模型價格

若 Provider 沒有真實成本回報且沒有模型價格，成本會標記為 unknown，不會當成零。
